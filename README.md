

# CARLOZ | TRAVEL HUB — Frontend

> **Led by Faith. Driven by Adventure.**  
> Premium travel and tour website for **CARLOZ | TRAVEL HUB**, based in Wayanad, Kerala, India.

---

## 🌲 Overview

**CARLOZ | TRAVEL HUB** is an authentic travel and road-trip service navigating the mist-covered hills, winding ghat roads, tea plantations, and waterfalls of Wayanad and the Western Ghats.

This repository contains the complete, production-ready frontend web application featuring:
- **Hero Poster Experience**: Inspired by editorial travel posters with monumental display typography and aerial photography.
- **Top Picks**: 4 portrait cards showcasing signature Wayanad sights with quick booking triggers.
- **"We create the trips you love"**: Human-centered brand story and custom vehicle features.
- **"Awesome Wayanad" & Stats**: Elevation, hairpin bend counters, and layered photography.
- **"EXPLORE ALL TOURS"**: Filterable tour packages (Weekend Odyssey, Friends Gang Road Trip, Heritage & Clouds, Custom Bespoke).
- **"WHICH ROUTE ARE YOU GONNA CHOOSE?"**: 3 arched doorway portals into Wayanad’s diverse landscapes.
- **Interactive Churam Mountain Route Visualizer**: 4-stage road journey from Thamarassery Churam 9 Hairpins to Banasura Sagar.
- **Interactive Multi-Step Trip Planner**: Generates prefilled WhatsApp enquiries directly to official desks.
- **Verified WhatsApp Integration**:
  - **Desk 1 (Primary)**: `+91 62388 13608`
  - **Desk 2 (Coordinator)**: `+91 81578 45547`
- **Two-Column FAQs**: Addressing custom itineraries, vehicle capacity, and pickup points.
- **Tailor-Made Trip Sunset Card**: Quick custom inquiry launcher.
- **Floating Multi-Desk WhatsApp Widget**: Instant one-tap access across mobile and desktop.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Dev Server**: [Vite 8](https://vitejs.dev/)
- **Styling**: Pure Vanilla CSS with comprehensive Design Tokens (`--bg-page`, `--color-terracotta`, `--color-forest`, clamp-based typography)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Fonts (*Syne*, *Outfit*, *Plus Jakarta Sans*, *Caveat*)
- **Deployment**: Configured for [Vercel](https://vercel.com/) via `vercel.json`

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/AjithMthomas/carloz-travelhub-frontend.git

# Navigate to directory
cd carloz-travelhub-frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be live at `http://localhost:5173/`.

### Production Build

```bash
npm run build
```

The compiled output will be generated in the `dist/` directory.

## 🌐 Vercel Deployment

This project includes a pre-configured `vercel.json` file for immediate deployment:

1. Push this repository to GitHub:
   ```bash
   git push -u origin main
   ```
2. Import the repository in your [Vercel Dashboard](https://vercel.com/new).
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**.
